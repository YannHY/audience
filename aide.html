Créez vos questions et affichez les réponses en direct

Aide

Guide rapide d'utilisation de la plateforme Audience

Créer un questionnaire

Depuis la page d'accueil, utilisez Créer un nouveau questionnaire pour ajouter vos questions et vos réponses.

Vous pouvez nommer votre questionnaire, ajouter autant de questions que nécessaire, régler le temps de réponse pour chaque question, puis lancer la session.

Dans la zone Préparer un lot de questions, vous pouvez aussi activer l'option Autoriser un rapport personnel en fin de questionnaire. Le créateur du questionnaire choisit donc explicitement si les participants pourront ou non consulter ce rapport une fois la session terminée.

Mettre en forme le texte

Dans l'intitulé d'une question, vous pouvez sélectionner du texte pour faire apparaître une barre de mise en forme.

Cette barre permet d'appliquer un gras, un italique, un soulignement, une liste numérotée ou une liste à puces.

Les raccourcis clavier Ctrl/Cmd+B, Ctrl/Cmd+I et Ctrl/Cmd+U sont également disponibles pendant l'édition.

Ajouter des formules mathématiques

Un bouton ∑ est disponible dans le champ de question ainsi que dans les champs de réponses possibles.

Il permet d'ouvrir un éditeur de formule et d'insérer une expression mathématique à l'emplacement du curseur.

Pour une question ouverte, vous pouvez aussi activer l'option Réponse mathématique afin que le participant réponde avec un clavier mathématique dédié.

Types de questions disponibles

  • Cases à cocher : plusieurs réponses possibles parmi plusieurs propositions.
  • Choix unique : une réponse choisie parmi plusieurs propositions.
  • Classement : remise en ordre d'éléments.
  • Évaluation : notation (étoiles/score).
  • Légender une image : placement d'étiquettes sur une image.
  • Nuage de mots : collecte de mots-clés en direct.
  • Réponse ouverte : texte libre saisi par le participant, ou réponse mathématique si l'option correspondante est activée.
  • Texte à trous : réponse à compléter dans des blancs.
  • Vidéo : question associée à un contenu vidéo.

Temps de réponse par question

Chaque question peut avoir une durée de réponse dédiée. Par défaut, la durée proposée est de 30 secondes.

Vous pouvez choisir parmi plusieurs durées (de quelques secondes à plusieurs minutes) directement lors de la création de la question.

Une barre de progression sous la question indique le temps restant côté participant et côté présentateur (vue live et résultats).

Pour les questions vidéo YouTube, le timer est masqué afin de laisser le temps de visionnage.

Diffuser une question en direct

Une fois la session lancée, Audience génère un code et un QR code à partager avec le public.

Les participants répondent via l'URL de réponse. Avant de voir la première question, ils sont invités à saisir le nom ou prénom qu'ils souhaitent associer à leurs réponses.

Les questions n'apparaissent que lorsque le présentateur clique sur Résultats live. Tant qu'aucune question n'est affichée, le participant voit simplement un message d'attente. Vous pouvez ensuite passer à la question suivante.

Le nombre de répondants connectés est affiché en temps réel en bas à gauche de l'interface.

Si le rapport personnel a été autorisé par le créateur, les participants voient, à la fin du questionnaire, un rapport personnel qu'ils peuvent consulter puis télécharger en PDF.

Afficher les résultats

L'onglet Résultats permet d'afficher les réponses en temps réel.

Selon le type de question, vous pouvez actualiser, afficher la bonne réponse, exporter en CSV et consulter le bilan final.

L'export CSV du bilan final reprend désormais les noms/prénoms choisis par les participants, afin d'identifier plus facilement qui a répondu quoi.

Lorsque cette option a été autorisée au moment de la création du questionnaire, chaque participant peut obtenir, à la fin du questionnaire, un rapport personnel qui récapitule ses propres réponses.

Ce rapport personnel distingue les réponses correctes, les réponses incorrectes et les réponses qui ne sont pas notées comme justes ou fausses (par exemple une vidéo, une notation ou un nuage de mots).

Quand une question est corrigée automatiquement et que la réponse donnée est fausse, le rapport indique aussi la réponse attendue. Le participant peut consulter ce récapitulatif à l'écran puis le télécharger en PDF.

Gérer vos questionnaires

Dans Mes questionnaires, vous pouvez retrouver vos questionnaires, les exporter, les importer ou les restaurer depuis la corbeille.

L'import fonctionne désormais de deux façons : soit en choisissant un fichier Markdown (.md), soit en collant directement le texte Markdown dans la fenêtre d'import.

Le format d'import/export est en Markdown (.md). Le contenu commence par un titre #, puis des métadonnées (par ex. - Code:, - Nombre de questions:). Chaque question est ensuite déclarée avec ## Question X, suivie de l'énoncé.

Pour un QCM, utilisez des choix avec cases Markdown (- [ ] et - [x] pour la bonne réponse). Pour les questions à Cases à cocher, ajoutez - Type: cases à cocher puis les options en - [ ] et - [x] (toutes les lignes en [x] sont considérées comme correctes). Pour les autres types, utilisez une ligne - Type: (ex. question ouverte, nuage de mots, classement, texte à trous, vidéo YouTube, notation en étoiles (1 à 5), légender une image) puis, si nécessaire, le bloc associé (texte à trous, éléments à classer, URL vidéo, étiquettes).

Pour une question ouverte mathématique, ajoutez après - Type: question ouverte une ligne - Format de réponse: mathématique.

Cas particulier « Légender une image » : l'import/export Markdown gère maintenant le type, l'image, le zoom et les étiquettes (positions incluses).

Voir un exemple 
# L'intelligence artificielle

## Question 1

À quelle année est généralement attribuée la naissance de l'expression « intelligence artificielle » ?

- [ ] 1945
- [x] 1956
- [ ] 1972

## Question 2

Qui a inventé l'acronyme IA ?

- [x] John McCarthy
- [ ] Yann Le Cun
- [ ] Alan Turing

## Question 3

Vrai ou faux ? Les réseaux de neurones naissent dans les années 80 ?

- [x] VRAI
- [ ] FAUX

## Question 4

Complète la phrase suivante.

- Type: texte à trous
- Texte à trous:
```
Un [LLM] est un modèle de langage de grande [taille] entraîné sur de très nombreux textes.
```

Compte et accès

Les pages Connexion, Profil et Administration permettent de gérer l'accès à la plateforme.

Si vous êtes administrateur, vous pouvez gérer les comptes et les paramètres liés à l'instance.

Mode clair / mode sombre

Le bouton en haut à droite permet de basculer entre les thèmes clair et sombre.

Votre préférence est mémorisée automatiquement.

Conseils pratiques

  • Préparez votre questionnaire avant la séance pour gagner du temps.
  • Testez une question avant de lancer la session en classe.
  • Exportez régulièrement vos données importantes.
  • Vous pouvez demander à une IA générative de rédiger un questionnaire directement au format Markdown compatible avec Audience, puis l'importer en quelques secondes.

Le plus simple est de fournir à l'IA l'exemple complet présenté plus haut dans cette page, afin qu'elle comprenne immédiatement comment structurer le questionnaire au bon format.

Une fois le texte généré, il suffit de le copier-coller dans la fenêtre d'import Markdown, ou de l'enregistrer dans un fichier .md puis de l'importer.
